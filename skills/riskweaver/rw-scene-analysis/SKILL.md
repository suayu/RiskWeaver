# 场景分析

读取[共享契约](../shared/contract.md)。按当前输入加载[策略配方](../shared/recipes.md)中相关族。

先核对source_step、坐标、活跃对象和缺失数据。使用工具给出的相对位置、速度差、道路关系、交互时间及裕度，指出哪些对象可能在有效期内影响自车。

把“没有物理交互机会”“模板不覆盖但可能有机会”“输入缺失”分开。画像样本不足时使用中性解释，不能把不确定估计当作已证实弱点。

输出可核验的短结论、证据ID、候选族和不确定性；连续锚点实例化、几何检查和风险计算交给代码工具。不要为提高覆盖率宣称每个场景都有攻击机会。
