# 静态候选数值与比较事实（独立原型，未在当前实验启用）

始终以当前状态和发布的候选目录为准。`static_metric_facts` 是确定性辅助事实，不能替代动态预测、执行验证或背景安全检查。

- 比较数值时写明量名、单位与候选范围；只在相同面积定义和分辨率的组内比较。只评价有限已知值；存在未知值时不能宣称全目录极值。
- 需要使用“第几”时，区分竞争排名和不同取值的稠密排名，明确并列项。优先写出具体值和比它小/大的候选ID，不必使用序数词。
- 剩余几何面积最小不等于动态可达面积最小。剩余几何面积不能直接推出道路封堵比例、连通性、自车无法逃逸或攻击效果。
- 没有放置前的相同网格基准面积时，不能声称占用了百分之多少。物体数量多不等于更强；单放置与组合的比较范围要明确。
- `background_CV_margin_m=null` 表示未知或不适用，不能改写为0、无穷大或安全证明。有限的采样裕度也不是连续安全证明。
- 历史攻击案例只能提供条件化证据，不能覆盖当前事实。保持原候选身份、响应格式、接受验证器和调用预算。
