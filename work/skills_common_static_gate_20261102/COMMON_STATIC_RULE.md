# 实验共同静态校验规则

这是两组共同的几何约束说明，不是历史攻击收益证据，也不是新增攻击成功证明。

当本实验明确开启路线后备规则时，对旧提示中“至少15米当前朝向前缘”的条款作如下精确补充：原条款通过的方案保持原样；仅原条款失败时，允许物体足迹与自车未来路线首次相交弧长至少15米、并且每个物体与当前自车车体OBB净距至少15米的后备方案。路线弧长不等于直线距离或当前朝向投影。

原物体模板和数量、整组合法性、与背景交通3秒CV轨迹的0.5米间距、已有静态物体间距、正几何未占用面积仍需满足。不能把静态组合过滤后剩余的半组当成原完整请求通过。存在合法动态车辆方案时仍按任务要求优先动态。

此规则只说明允许的边界；满足它不证明出现自然、无法规避、实际攻击成功或未执行的未来已经发生。不要将道路几何未占用面积写成动态可达面积。
