# RiskWeaver 最小消融冻结协议

## 参照组

使用 `riskweaver_profile_formal_idm_rl_20260924_r4/idm_profile_on` 作为完整动态参照：20 个冻结场景、IDM、完整历史画像、场景条件化候选、均匀预算、`qwen3-coder-plus`、阶段锚点开启、纯动态轨迹。

## 新增组

1. `anchor_uniform`：保持画像与纯动态模式，只关闭 `anchor_drive_enabled`。该组仍保留旧版均匀 LLM 锚点损失，隔离分阶段锚点权重与安全候选重排的增量。
2. `joint_dynamic_static`：保持完整画像与阶段锚点，切换为 `joint` 并开启参数化静态障碍候选，测量静态道路风险对纯动态参照的增量。

## 共同协议

- 与参照组使用同一 20 场清单、顺序、seed 42、IDM 和最多 400 帧。
- 固定 `qwen3-coder-plus`，每场最多 4 次规划；不在运行中更换模型。
- 难度控制和多 Agent 关闭；diffusion、动力学投影、安全门槛和其余权重固定。
- 报告攻击计划、实际攻击场景和帧、障碍计划及暴露帧、D/TTC/EA/可达区域、能力分、生成失败、服务失败和背景碰撞。
- LLM 服务为外部非确定系统，因此消融保证场景、模型和预算配对，不宣称逐请求响应完全相同。
- 任一组出现最终规划服务失败则该组无效并停止后续组；失败尝试不筛除。
