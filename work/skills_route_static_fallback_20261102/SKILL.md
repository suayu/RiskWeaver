# 路线相关的静态放置距离（独立可选原型）

状态：已做确定性测试，尚未通过真实LLM及闭环验收。只在代码明确启用路线后备规则时使用，不改变旧模式。

- 原15米当前朝向前缘检查通过的候选保持原样；仅在它失败时，代码可以检查真实障碍物足迹与未来路线中心线首次相交的弧长距离是否仍至少15米。
- 路线弧长与当前朝向投影不是同一量，弯路上可能出现前向投影不足15米而路线相交点仍很远。不要将其写成降低到零米或忽略初始碰撞。
- 后备候选还必须保留初始自车OBB间隔、整组模板合法性、非目标交通安全和正几何面积检查。身份和生命周期规则不变。
- 路线缺失、投影圈次歧义或没有足迹与路线相交时，不捏造后备证书。后备通过也不是动态可达性、自车必然碰撞、无法逃逸或已执行的证据。
- 仍按动态优先、无可用动态候选再选择已发布静态组合的策略工作；不自行编造未发布的障碍物。
