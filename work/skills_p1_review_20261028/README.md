# P1完整规划机会审查材料

本工具在终态实验上只读运行，不调用API、不使用GPU、不改变运行时，不替代原四组独立运行验收。

过去仅审了19个接收计划的场景分析和选中理由，未审拒绝、空目录、完整排序。这里将每个`llm_output`纳入，把同场同源帧的全部SDK原始请求/回复、确定性位姿事实、完整候选/排名/理由和原始执行标记整理到独立目录。没有规划输出和未尝试场景仍在预定分母。

所有语义结论初始为“未审”，正确攻击率为null。HTTP成功、schema通过、grounding通过、执行标记、正CV中心距差都不能自动认证正确攻击。候选库最大CV差值与选中值的差只作诊断，保留负值和不完整条目；不当作战术最优差距或新的运行门控。

需要逐条核查：源身份与时间；实际方位/航向；数值比较；全部排序理由；选中策略适用性；真正引导执行归属；实测威胁。每个支持或矛盾结论应引用原文及可复核的状态/指标。无法判定保留indeterminate，不能为完成多数覆盖目标把它自动设为正确。工具不声称独立人工金标或审稿人共识。

`execution_markers`仅按目标和声明时域收集原始标记，不认证request归属；真正归属沿用`skills_actual_increment_audit_20261026/audit.py`和原验收器。本工具不证明自然语言、画像、静态或目标难度模式已完成。

用法：

```text
python build_review.py --experiment <已终态实验目录> --output <独立新输出目录>
```

输出完整JSON、中文HTML、UTF-8 CSV审查队列及输入/分析源码SHA。运行中实验拒绝导出，禁止写回实验目录，已有衍生输出不覆盖。
