# RiskWeaver 自车画像正式实验冻结协议（2026-09-24 R3）

## 目的

在 IDM 与 GPUDrive RL 两类自车策略上，以场景为配对单位比较完整画像关闭/开启。
R3 保留 R1/R2 全部失败产物。R2 的完整规划预检发现 HTTP 200 非 JSON；增加百炼官方 JSON Object 请求后，`qwen-plus-0112` 仍产生语义矛盾计划。R3 冻结为通过同一真实场景完整 schema 与物理验证 smoke 的模型，并从头运行四组。

## 冻结设计

- 场景：`riskweaver_profile_formal_manifest_20260923.json` 中 20 场，顺序及哈希不变。
- 组别：`idm_profile_off`、`idm_profile_on`、`rl_profile_off`、`rl_profile_on`。
- 随机种子：42；每场运行至自然结束、最多 400 帧；最多 4 次高级规划调用。
- 百炼模型：仅 `qwen3.5-flash-2026-02-23`。该模型在真实场景完整 planner smoke 中于 3.69 秒返回合法攻击计划，并通过本地语义和动力学校验；四组完全相同，禁止运行中更换以避免模型混杂。
- 攻击模式：纯轨迹；无静态障碍物；单 LLM agent。
- 公共连续组件：同一 diffusion、动力学投影、AnchorDrive 风格阶段锚点引导与安全门控。
- 唯一组内干预：画像关闭使用原离散规划；画像开启使用完整历史画像、场景条件化候选、历史收益和封闭候选排序。

## 有效性门槛

- 任一组退出码非零或存在真实规划服务失败，launcher 停止，组标为无效。
- HTTP 200 后的无效 JSON、schema 或本地计划验证失败计入生成/验证失败，不伪装成服务故障。
- 所有尝试、无攻击、生成失败及 `D=null` 均保留。
- 背景车间及背景车—静态障碍物碰撞必须为 0；否则单独报告，不能作为有效安全结果。

## 主要终点

1. 有效攻击覆盖率与实际攻击帧；
2. 攻击条件 D、全场有效 D 及覆盖率；
3. TTC、EA、可达区域、能力分；
4. 生成失败、安全拒绝与规划耗时；
5. 画像开启减关闭的场景配对差与 bootstrap 95% 区间。

R1/R2 仅作为失败审计，不与 R3 拼接或选择性合并。
