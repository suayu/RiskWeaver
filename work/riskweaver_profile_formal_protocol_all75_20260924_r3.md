# RiskWeaver 自车画像正式实验冻结协议（全量 75 场，2026-09-24 R3）

## 规模依据

SAFE-SIM 论文正文未明确披露碰撞率表格的场景数；其官方 README 主命令和开源运行脚本默认值均为每项 100 场。服务器现有同域 Waymo 200 m 初始场景共 75 个，因此纳入全部 75 个互异场景，达到相同量级并避免用重复随机种子冒充独立样本。20 场批次仅作为工程先导，不进入 75 场正式统计。

## 冻结设计

- 清单：`riskweaver_all_75_unique_manifest_20260924.json`，按文件名排序纳入目录中全部 75 个 `.pkl`，记录逐文件 SHA-256。
- 组别：`idm_profile_off`、`idm_profile_on`、`rl_profile_off`、`rl_profile_on`。
- 随机种子：42；每场最多 45 帧；每场最多 4 次高级规划调用。
- 百炼模型：四组统一冻结为已经通过真实封闭排序 smoke 的 `qwen-plus-0112`。
- 攻击模式：纯动态轨迹；无静态障碍；单 LLM agent。
- 公共组件：相同 diffusion、动力学投影、阶段锚点引导与安全门控。
- 唯一组内干预：画像关闭使用原离散规划；画像开启使用完整历史画像、场景条件化候选、历史收益与封闭候选排序。

## 有效性和统计

- 任一组退出码非零或出现真实规划服务失败，立即停止后续组并保留全部产物。
- HTTP 200 后的 JSON、schema 或计划验证失败计入生成/验证失败，不计作服务故障。
- 保留全部无攻击、生成失败、拒绝和 `D=null`。
- 背景车间及背景车—静态障碍物碰撞必须单独报告。
- 以独立初始场景为统计单位，报告配对 bootstrap 95% 区间；不得将帧当作独立样本。
- 主要终点：有效攻击覆盖、实际攻击帧、攻击条件 D、全场 D 与覆盖率、TTC、EA、可达区域、能力分、失败类型、耗时和背景安全。
