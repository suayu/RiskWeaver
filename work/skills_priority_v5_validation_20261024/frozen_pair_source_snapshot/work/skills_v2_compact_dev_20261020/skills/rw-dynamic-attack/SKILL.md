# Dynamic ranking
Use [contract](../shared/contract.md) and [recipes](../shared/recipes.md).
Return a best-first prefix of at most six IDs; the executor can attempt at most six, so a full permutation is unnecessary. Every ranked ID needs one concrete evidence-based reason.
Prefer low response margin supported by interaction timing, background clearance and actual profile evidence. Do not maximize acceleration itself or assert inevitable collision. TTC beyond three seconds is extrapolated, not a sampled encounter; null TTC is not proof of impossibility.
Small terminal offsets such as 0.03 versus 0.26 metres are both small. Do not label one a significant lane departure without a supplied corridor test. The family label is an intent classification, not proof of real merge topology.
