# 技能评估

读取[共享契约](../shared/contract.md)。固定开发/测试清单、模型、seed、攻击/采样预算与diffusion求解器参数。

分别报告服务、契约、候选覆盖、计划接收、连续可行率、实际攻击场景/帧、有效D覆盖、背景安全、真实性及耗时。无有效D保持null，零攻击不得用一般交通风险冒充攻击收益。

技能消融固定候选；目录扩展另做消融。画像因果验证比较正确/无/错配历史。报告无条件覆盖及有交互机会的条件覆盖，保留全部失败分母。

技能只能在开发数据修订，正式测试冻结版本。少样本bootstrap区间不能证明非劣效；跨预测源D、跨适配基线和混用模型须保留解释边界。
