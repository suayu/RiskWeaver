# 有界计划修复

读取[共享契约](../shared/contract.md)。先确认失败层和状态是否仍有效。

契约错误按当前schema修复，不引用旧request_id或不存在ID。候选第一名被拒时，优先由代码检查同次排序的后续项；不为此自动增加模型调用。

所有候选同规则失败时报告模板/验证一致性问题。空目录不能靠编造ID修复。连续轨迹不可行时，只在运行器已批准的候选和预算内建议下一项。

引用实际失败指标、阈值、时刻和对象，不假造“修复后已通过”。不降低背景安全、动力学或有效区域要求。预算耗尽保存原因并退出；最终服务失败不得改写成正常无攻击。
