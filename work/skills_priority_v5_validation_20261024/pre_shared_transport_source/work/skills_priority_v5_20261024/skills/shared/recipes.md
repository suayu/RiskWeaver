# Compact recipes (development, not new closed-loop validation)
- forward_pressure / slow_down: compare longitudinal closure and time-aligned distance; use non-target clearance. Do not equate braking with a guaranteed ego reaction.
- cut_in / merge_conflict: use relative side, heading and time-aligned proximity. A near-zero terminal lateral offset alone does not prove collision or a real road merge.
- rear_pressure: only use supplied rear candidates; test if relative motion permits interaction within the intended horizon.
- bounded_acceleration_sparse_intent_v1: source code caps acceleration at 3.8 m/s² and applies original screening. No new continuous policy is generated by the model.
- static layout: only select supplied compatible obstacle IDs when enabled; otherwise never propose an obstacle.
When estimated risk is tied or null, use within-horizon proximity and uncertainty, not invented precision. State that predicted events after the plan's active duration may not be realized.
