## 修改前后

原IncrementalSkillsPlanner提供稀疏意图/CV事实和contrast_direction校验，未强制返回当前目标相对位置或航向关系。新原型在其外增加显式布尔参数`fact_grounding=False`。

开启时：

1. `scene_facts.py`从当前`ego_state`及带ID的当前`agents`生成事实卡。坐标是自车右/前方向；0.5米表示方位对齐带，既有0.7/2.4弧度航向分界原样沿用。它们只用于事实描述，未引入攻击对象位置/速度资格门控。
2. 每个排序候选的grounding增加`scene_fact_id`、`source_step`、`longitudinal_relation`、`lateral_relation`、`heading_relation`。几何数字在卡内供解释，但不要求模型重新抄写长浮点数。
3. 新校验先核对关系、时间和引用，再向原校验传递剥离新增字段的深拷贝；原对象、有效期、schema、contrast及安全流程继续执行。原响应不被改写。
4. 错误沿现有一次schema修复和4次总请求预算处理，不额外调用模型、不自动无限重试。真实服务/物理预算仍需未来入口共用既有公共装配。
5. 关闭时不添加事实卡、响应字段或额外协议，实际规划请求与原路径在归一化随机request_id后相同。

## 关键边界

- 本原型检查类型化关系主张，不能自动认证自由文字、最优策略或真实攻击增量。
- 模型原文和选中理由仍保留；不能用确定性改写文案掩盖模型原始错误。
- 抄对事实字段是身份/一致性证据，不足以单独证明理解。P1仍需独立审查选择和理由；P2需要实际执行与威胁证据。
- 新字段可能增加tokens和schema拒绝，覆盖率可能变差；在真实公平对照前不宣称效果提升。
- 首批为纯动态独立原型，未验证静态/画像/NL/难度控制，也未替代原A–E阶段。
- 扩散、锚点损失、权重、样本、安全阈值、D定义和正在运行的实验均未改。
