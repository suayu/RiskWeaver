# 静态布局选择

读取[共享契约](../shared/contract.md)和[施工配方](../shared/recipes.md)。

只选择当前目录提供的障碍候选ID；由代码实例化几何。说明占据哪些车道/道路区域、预期压缩什么响应空间、为何与所选动态候选兼容。不能用示意图代替尺度或碰撞计算。

施工区域由细长水马组成近矩形占道范围，实际坐标和排列以代码工具结果为准。没有背景安全或初态几何证据时标为待验证，不声明安全。

运行模式为纯动态时不加载本技能，不生成障碍计划。测量无效、工具失败和布局不可行分别报告。
