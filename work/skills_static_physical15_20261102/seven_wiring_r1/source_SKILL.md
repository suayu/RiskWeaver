# 路线后备静态组合：新增分支保留15米物理净距

本技能仅在明确开启`static_route_physical15`时使用。它是固定规则，不是RAG历史案例。当前只有目录和零API接线证据，没有新鲜LLM/闭环效果认证。

- 有可用动态车辆目录时仍优先动态；没有可用动态目录时，选择代码发布的静态组合ID。不要编造未发布物体、车辆或自由锚点。
- 原当前朝向前缘15米规则通过的候选保留。**仅原规则失败时**，新增后备要求真实足迹与未来路线首次相交弧长至少15米，且每个物体到当前自车的OBB净距至少15米。
- 后备物理15米与背景交通0.5米安全裕度是不同对象的约束；后者没有被改成15米，也没有被取消。物体类型、整组复核、背景CV安全和正几何未占用面积仍由代码检查。
- 路线弧长不是欧氏距离，当前朝向投影也不是沿路线距离。不要用“路线很远”证明物理上不贴近自车；以代码给出的具体量和范围为准。
- 原成功分支保留，不表示所有原有候选都重新满足了15米OBB净距。后备规则通过不证明无法逃逸、动态可达性、连续安全、出现自然或已经攻击成功。
- 选择后仍以最新状态复查整个组合。若状态变化使方案不合法，保留拒绝，不更改目录或放宽条件来强行通过。
- 数据未知、目录为空或服务失败应分别说明。目录250初态并集覆盖不是模型正确理解率或实际攻击率。
