# RiskWeaver 自车画像正式实验冻结协议（2026-09-23）

## 范围

本实验回答：完整历史画像、场景条件化候选和历史收益检索，是否能在不同自车策略下提高有效对抗场景生成覆盖，并形成可量化的低反应余量风险。

- 自车策略：IDM、GPUDrive RL。
- 每种策略分别运行画像关闭与画像开启，共四组。
- 场景：预先冻结的 20 场；其中 12 场来自 test split，8 场来自 validation split。结果必须按 split 分层，并明确不是纯 test 集。
- 所有组使用相同场景顺序、seed=42、45 帧、最多 4 次 LLM 调用、纯轨迹攻击、同一 diffusion、同一动力学投影、同一 AnchorDrive 风格锚点和同一安全门槛。
- 画像开启组启用完整方法；画像关闭组保留自由 LLM 高级规划。两组都不启用可控难度、多 Agent 或静态障碍物。

## 主要终点

1. 有实际攻击执行的场景比例。
2. 实际攻击执行帧数及每场分布。
3. 有效攻击记录覆盖率与攻击条件危险度 D。
4. 规划成功、验证通过、diffusion 执行之间的转化率。

## 次要终点

- 全场有效 D 与 D 覆盖率；必须与无攻击自然风险分开。
- 最小 TTC、规避加速度 EA、可达区域变化。
- 能力分 S、碰撞、完成路线与投影进度。
- 生成失败率与失败原因分布。
- 背景车间和背景车—静态障碍物碰撞。
- LLM 调用耗时、总耗时和模型回退。

## 统计规则

- 场景为独立配对单位；画像开减画像关使用配对 bootstrap 95% 区间。
- D=null 保持缺失，不写成 0。
- 所有失败、无攻击和规划服务错误计入分母。
- 无攻击条件下发生的自然碰撞不计为攻击收益。
- 若两组均有攻击，比较攻击条件 D；若画像关闭无攻击，报告覆盖差异并将 D 效应标记为不可估计。
- 结果先整体报告，再按 test/validation split 和自车策略分层。
- 本次正式运行开始后，不依据结果修改门槛、场景或参数。公共工程错误修复后只能在新目录补跑缺失项，并保留原失败记录。
