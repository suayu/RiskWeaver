# 当前攻击拒绝检查项与审计边界

核对范围：2026-09-17 远端 RiskWeaver-deb 当前工作树。阈值来自当前代码与配置；历史批次应以各自 resolved_config.yaml 为准。以下区分未发起规划、候选被筛掉、LLM 返回后被拒绝、连续轨迹被拒绝。默认单 Agent 与非画像模式不会启用全部画像专属检查。

## 1. 调度与服务：可能没有新攻击，但不等于安全检查失败

- 攻击未到期、未到下一规划时刻，不产生新请求；已到期计划清除，不得继续执行。
- 每场景规划次数达到上限停止新查询；当前默认上限 30，冒烟配置为 6。这是规划机会数，不等于多 Agent 内部真实 API 请求数。
- 规划器不可用、连接/鉴权/额度/超时等服务失败；连续失败触发熔断。服务失败必须单独计数，不能当作正常无攻击。
- 模型可明确输出不攻击理由。JSON 格式、字段类型、request_id 不匹配、缺失理由等则属于计划协议失败。

## 2. 画像规则候选：LLM 调用之前

来源：policies/ego_profile.py 的 CandidateBuilder.build/screen。

|检查|当前条件或阈值|拒绝/无候选表现|
|---|---|---|
|输入几何|自车与背景车状态有限、尺寸为正、道路非空且非退化|missing_vehicle_geometry、invalid_vehicle_geometry、missing_road_geometry|
|攻击对象适用范围|自车前向距离严格在 5–45 m；横向绝对距离 ≤7 m；航向差 ≤0.7 rad；目标速度 ≥1 m/s|对象不进入候选，旧日志未逐项计数|
|策略模板|同车道减速候选要求三秒后速度不为负；侧向候选使用切入，航向差 >0.12 rad 才额外提供合流|可能没有可生成模板|
|锚点|4×2 个有限坐标；首锚点距目标真实位置 ≤0.01 m|invalid_anchors 或 dynamics|
|锚点运动学|隐含速度 ≤35 m/s；相邻段速度差 ≤4 m/s（锚点间隔 1 s）；第一段速度与当前速度差 ≤4 m/s|dynamics|
|道路|目标车四个车身角点到最近中心线距离 ≤1.8 m；三秒内每 0.05 s 检查|road_corridor|
|背景安全|候选与其他背景车匀速预测及静态障碍物的 OBB 投影间距 ≥0.5 m|background_margin|
|自车规避见证|延迟 0.4 s 后以 4 m/s² 制动，必须与目标保持 ≥0.3 m 间距|no_avoidance_witness|
|规避后背景安全|同一制动见证与其他背景车及障碍物间距 ≥0.3 m|avoidance_hits_background / avoidance_hits_static|
|规避道路范围|规避路径距路线的距离加自车半宽 ≤1.8 m|avoidance_off_route|
|交互强度|预测 TTC 必须存在且在 [1,4] s|outside_ttc_band|

这些是有限采样、常速背景假设下的筛查，不是连续时间安全证明。任何一项先失败即返回，旧日志通常只记录该原因的计数，未保存失败候选坐标与指标值。

## 3. LLM 输出验证

来源：policies/profile_planner.py、policies/llm_adversarial_planner.py。

- 画像模式必须排序封闭候选目录；ID 不得杜撰、重复、缺漏，request_id 必须匹配。空排序必须给出不攻击理由；非空排序不应同时声称不攻击。
- Codex 画像协议必须准确匹配候选目标、策略、锚点与 duration。
- 不得输出连续轨迹、控制量或 inner_lr、inner_beta、n_guide_steps 等优化器参数。
- 动态攻击目标必须属于当前规划参与者；锚点必须为四个有限二维坐标。
- 通用锚点门槛：首点位置差 ≤4 m、首段速度差 ≤20 m/s、隐含速度 ≤50 m/s、隐含加速度 ≤20 m/s²。
- 1/2/3 秒锚点与自车对应匀速预测位置的最近距离必须 ≤15 m，确保存在交互；cut_in 末点在自车局部系的横向绝对距离必须 ≤6.5 m。
- 仅障碍物模式不允许动态攻击；未开启障碍物功能时不接受 obstacle_plan。

画像候选筛查比通用锚点验证更严格；两套阈值属于不同阶段，不能混为一套。

## 4. 静态障碍物与动态—静态组合

- obstacle_plan 必须为列表，最多两组模板；每项结构、模板类型、尺寸/count 等需通过模板解析。disabled_vehicle 的 count 必须为 1。
- 与已有静态障碍物中心距离不能小于 2 m；展开后的真实前缘距自车前方必须至少 15 m。不合格障碍物组可单独被过滤，未必拒绝整个动态计划。
- 画像障碍物候选还检查放置位置前向距离 16–45 m、道路走廊、背景 OBB ≥0.5 m、自车制动见证 ≥0.3 m，并逐个检查与动态候选兼容性。
- LLM 只能选择已列出的 obstacle_candidate_id，不能选择与排名第一的动态候选不兼容的障碍物。

## 5. Diffusion 联合候选选择

来源：policies/diffusion_model_wrapper.py、policies/joint_safety.py。

- 第 0 个样本是逐车选择后拼接的结果，不当作可选联合样本。当前总计 8 个样本，实际候选为后面 7 个。
- 候选评分必须有限，坐标、朝向、尺寸及变换必须有效。
- 所有背景车对在预测点与相邻中点进行 OBB 检查；当前该阶段间距要求 ≥0 m。无合格联合候选时拒绝。
- 该阶段通过不代表后续画像的 0.5 m 裕度或动力学门槛已经通过。

## 6. 可选连续动力学修正

来源：policies/trajectory_projection.py，默认关闭。

- 无完整有效联合轨迹、形状错误、非有限输入或无效约束配置时拒绝。
- 每车求解超过 2 s、100 次迭代内未成功时拒绝。
- 求解后重新按真实起点差分计算速度、加速度、jerk 和位移；仍超限时拒绝。
- 相对原轨迹任一点改动超过 0.25 m 时拒绝。修正成功不等于道路或背景安全通过。
- 当前开启投影必须同时具备画像全时域验证器；否则启动时报配置错误。

## 7. 画像联合执行门禁

来源：policies/ego_profile.py 的 validate_joint。

|检查|当前阈值|拒绝码|
|---|---|---|
|完整性|联合轨迹非空、至少两预测点、全部 valid；车辆 ID 与全部活跃背景车完全一致|profile_missing_joint_prediction / profile_incomplete_joint_prediction|
|几何|车辆与预测坐标、朝向有限；道路存在|profile_invalid_agent_geometry / profile_invalid_joint_geometry|
|速度|所有背景车、完整预测时域 ≤20 m/s|profile_joint_dynamics|
|单步位移|≤2 m|profile_joint_dynamics|
|加速度模长|≤6 m/s²|profile_joint_dynamics|
|jerk 模长|≤12 m/s³|profile_joint_dynamics|
|道路|起点、全部预测点及中点，所有车身角点距最近道路中心线 ≤1.8 m|profile_joint_road_corridor|
|背景车间距|上述检查点的 OBB 间距 ≥0.5 m|profile_joint_background_margin|
|背景—障碍物间距|上述检查点的 OBB 间距 ≥0.5 m|profile_joint_static_margin|

这里包含真实起点：起点已经越界时，未来轨迹修正无法使其合格。攻击目标的 route guidance 豁免是软损失设置，并不豁免这套硬道路门禁。

## 8. 可规避性与最后执行检查

- 画像攻击必须取得有效可达性事件与有限 difficulty，并且 dangerous_solvable 为真。缺失/无效测量：profile_avoidability_invalid；没有可达规避解：profile_no_reachable_avoidance。
- 即将执行的真实起点、首预测点及其中点再次进行背景 OBB / 静态障碍物检查；缺失首帧、无效几何、重叠均拒绝执行。
- 联合轨迹源帧与当前仿真帧不一致、未知/缺失车辆 ID 等属于集成错误，会阻止执行。
- D 没有有效 EA 与可达性窗口时为 null。这是观测有效性规则，不应单独解释为一次攻击被拒绝。

## 9. 多 Agent 特有的阻止条件

- 未知模式、超时配置无效、离线记忆缺失或格式错误、记忆与当前评估场景重叠时失败。
- 第四模式需要画像条件上下文；当前多 Agent 编排不支持 Codex 队列后端。
- 任一在线角色发生服务失败，整个协作请求标为服务失败；不能拿另一成功提案掩盖故障。
- 每个角色仍走原 LLM 校验；仲裁只在已验证的提案中选择，不授予任何安全豁免。

## 10. 当前具体案例

1. 原动力学拒绝：第 10 帧所选样本最大 jerk 约 20.05 m/s³ >12，主要违规车辆为背景车 1。7 个可选联合样本均有动力学不合格项。
2. 投影后道路拒绝：背景车 1 真实起点角点距离约 1.9319 m >1.8 m，超出约 0.1319 m；另一角点为 1.9061 m。目标车 2 的离线重算未来角点最大距离约 2.6035 m，同样超限。后者属于冻结参考样本上的离线复核，不是已执行轨迹。
3. 无候选场景：两批场景中多次候选目录为空，实际没有 LLM 调用，也没有攻击引导的 diffusion 未来轨迹。图册保留每次规划点的候选拒绝计数；没有记录的具体指标值标为未知，不能假造。

既有代码采用遇到首个失败即退出的方式。因此同一计划可能同时违反多项限制，而原始结果只保存首先触发的原因。图册的离线复核可以揭示额外问题，但不会改写原实验的拒绝理由或有效性。
